# 전체 IA → CMS 관리 대상 매핑 초안

이 표는 운영 검토 자료다. IA나 페이지를 생성하는 실행 설정이 아니며, 이번 단계에서 실제 연결값을 저장하지 않는다. 숫자 page/block ID는 현재 원본에서 확인한 값만 사용한다. 콘텐츠 필터의 사전 code는 적용 시 해당 환경의 실제 숫자 ID로 해석해야 한다.

- page: 고유 페이지 원본과 공통 PageEditor.
- block: 해당 페이지의 블록. 본문 소제목은 별도 block ID가 아니다.
- content-list + filter: 공통 콘텐츠 목록과 같은 ContentEditor에 연결한다.
- menu: 방문자용 진입점이다. 관리자 목록 URL을 방문자 메뉴 주소로 쓰지 않는다.
- 개념 묶음: 화면/지면의 구분 후보이며 DB 저장 대상이 확정된 것이 아니다.

현재 V10 메뉴에는 parent_id·block_id·분류 필터 필드가 없고, 관리 트리는 기존 코드에 등록된 콘텐츠 경로와 실제 페이지/메뉴/블록을 조합한다. 따라서 이 표 전체를 사전 등록만으로 구현할 수는 없다. 인터뷰 글/동영상은 아직 서로 다른 필터로 분리할 수 없다.

상위 4개 영역의 방문자 메뉴와 실제 공개 URL은 후보로만 둔다. 기존 HOME·소개 외 페이지 생성, 하위 메뉴 노출 깊이와 landing page 여부는 별도 결정한다.
