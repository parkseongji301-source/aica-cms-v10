# 공통 관리자 디자인 조정

2026-09-29 사용자 제공 티스토리 관리자 이미지를 참고하여 AICA 관리자 공통 스타일을 조정했다. 개별 화면 기능 구조·메뉴·경로·입력·저장 동작은 변경하지 않는다. 8번 이후 화면 개선과는 별도 작업이다.

- 연한 회색 배경 `#f4f5f6`, 흰 사이드바·헤더·작업면, 얇은 중립 회색 경계선 `#e0e2e5`.
- 블루는 로고·현재 선택 상태·주요 CTA를 중심으로 사용. 보조 링크·스크롤바·조회 수치·보조 버튼은 중립 색상으로 정돈.
- 공통 패널과 버튼 모서리를 대체로 3px로 줄이고 패널 그림자를 제거. 데스크톱 본문 좌우 여백 40px, 제목 25px/600, 보조 문구 13px 기준.
- 흰 보조 버튼과 블루 주요 버튼, 선택 탭을 구분. 오류·미게시 수정·게시 상태 등의 의미 색상은 유지.
- 기존 작성 본문·저장 서식·홈페이지 미리보기 콘텐츠의 타이포에는 새 규칙을 적용하지 않는다.

구현은 `frontend/src/calm-shell.css`와 `main.tsx`의 스타일 import 한 줄이다. 기존 디자인 위에 공통 표시 기준을 적용하며 React 상태·API·DB·권한·발행·버전·휴지통 로직 변경 없음.

TypeScript 검사·빌드·diff 공백 검사 통과. 동일 V11 JAR의 별도 메모리 예시 환경에서 콘텐츠 목록·글쓰기·관리 대시보드와 390px 모바일 메뉴를 시각적으로 확인했다. 모바일 가로 넘침 없음. 기존 공개본과 실제 운영 데이터의 작성·게시 작업은 수행하지 않았다. 이번 CSS 변경에 새 기능 테스트는 추가하지 않았다.

8095 적용 전후 36개 테이블 fingerprint·schema·migration 이력 및 승인 JAR·receipt·원래 실행 설정 해시 동일. 최초 적용 증거는 `.cache/calm-shell/result.json`. 실행 방법은 [콘텐츠 작업 홈](CONTENT_WORK_HOME.md)을 따른다.

## 공통 디자인 보완

사용자가 승인한 추가 세 가지를 같은 공통 CSS에 반영했다.

- 사이드바 그룹 구분선을 없애고 24px 상단 여백으로 구분. 그룹 제목은 13px/500의 중립색으로 낮추며 현재 선택한 메뉴의 파란 강조를 유지한다. 하위 메뉴는 계속 펼쳐 보인다.
- 경로·화면 컨테이너·하단 안내에 동일한 최대 1440px 폭과 중앙 정렬을 적용한다. 개별 설정 폼의 좁은 폭과 작성 본문 폭은 유지한다.
- 사이드바 보조 설명은 12px, 목록 분류·작성 안내 등의 보조 문구는 13px와 충분한 대비로 정돈했다. 본문 저장 서식과 미리보기 콘텐츠에는 적용하지 않는다.

1920px 예시 화면에서 경로·콘텐츠 목록 작업면이 같은 시작선과 1440px 폭임을 확인했다. 관리 화면에도 동일한 폭 기준을 확인했고, 390px 모바일 메뉴의 가독성과 가로 넘침 없음을 확인했다. TypeScript·빌드·diff 검사 통과. 기능 구조·상태·라우팅 변경 없음.

현재 UI: `.cache/ui-releases/calm-shell-20260929-2`. 적용 전후 검증 자료: `.cache/calm-shell-refine/`. 직전 디자인 release는 보존한다.
