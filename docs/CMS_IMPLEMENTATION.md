# AICA 백오피스 구현 범위

## 실행

```powershell
.\scripts\mvn-local.ps1 -B -ntp -Pegov43-probe verify
.\scripts\run-local.ps1
```

- 관리자: http://127.0.0.1:8081/admin
- 로컬 최초 계정: 아이디 `1234` / 비밀번호 `1234`
- local 프로필은 127.0.0.1과 지정된 파일 DB에서만 기동합니다. 일반 운영 계정의 비밀번호 정책은 유지합니다.
- DB: `.local-data/aica-local.mv.db`. 글, 페이지, 미디어, 설정, 계정은 재시작 후 유지됩니다.
- 기존 데이터가 있으면 다시 초기화하지 않습니다. 이전 콘텐츠 8건과 사용자가 저장한 데이터는 보존합니다.
- 기존 dev DB와 실행 스크립트도 유지합니다. design-preview는 이전 메모리 DB 확인용 프로필입니다.

## 홈페이지 연결 범위

현재는 실제 홈페이지에 연결하기 위한 백오피스만 제공합니다. 가상의 홈페이지 컨트롤러·템플릿·스타일과 `/site` 바로가기를 제거했습니다. 공개 데이터 조회 API도 아직 노출하지 않습니다. 실제 연결 대상이 정해지면 그쪽의 URL 규칙·인증·데이터 계약에 맞추어 발행 모델과 설정을 연결합니다.

‘발행본 저장’은 백오피스 DB에 확정본을 보관하는 동작입니다. 외부 사이트를 수정하거나 배포하지 않습니다. 미리보기는 로그인한 사용자가 본문·섹션을 확인하는 내부 화면이며, 향후 홈페이지와 완전히 동일한 결과를 보장하는 화면이 아닙니다.

## 글쓰기와 페이지 본문

- 기본 고딕·명조·고정폭, 14/16/20/28 크기, 제목 1–3, 굵게·기울임·밑줄·취소선, 글자색·배경색, 정렬.
- 글머리/번호 목록, 인용문, 코드 블록, 링크, 구분선, 표(최대 20행 × 8열).
- 커서 위치에 사진과 문서를 삽입합니다. 파일 선택, 사진 파일 드래그, 클립보드 이미지 붙여넣기, 미디어 보관함 선택을 지원합니다.
- 사진 클릭: 본문 너비 25/50/75/100%, 왼쪽/가운데/오른쪽 정렬, 대체 텍스트·설명, 위/아래 이동, 제거.
- 문서 클릭: 표시 이름 수정, 위/아래 이동, 제거. 미리보기·저장본에서 다운로드합니다.
- 왼쪽 편집 / 오른쪽 실시간 미리보기. PC·모바일 폭 전환과 관리자 메뉴를 접는 집중 모드.
- 입력이 멈춘 뒤 약 1.8초 후 서버에 자동 임시저장. 제목이 있어야 저장합니다. 새 페이지 주소 식별자는 자동 생성하며 기존 식별자는 빈 입력으로 변경되지 않습니다. 저장 시각·실패·충돌을 표시합니다. 수동 저장과 Ctrl/Cmd+S도 지원합니다.
- 업로드·저장 진행 중 또는 저장되지 않은 변경이 있으면 페이지를 떠날 때 알립니다. 충돌 시 자동 덮어쓰기를 중지하며 작성 중인 내용을 화면에 유지합니다.
- 페이지 섹션 본문에도 같은 편집기를 사용하며 추가·삭제·순서·노출 변경을 미리보기에 즉시 반영합니다. 콘텐츠 목록 섹션은 연결 위치를 표시합니다.

## 저장 형식과 검증

Quill 2.0.3 배포 파일과 BSD 라이선스를 프로젝트에 포함해 CDN 없이 동작합니다. 원시 HTML 대신 서버에서 허용 항목을 검사한 Delta JSON을 저장합니다. 링크 스킴, 서식 값, 이미지·파일 소유권, 참조 수, 본문 길이, 표 크기를 검사합니다. 서버 확인 화면은 이 JSON에서 고정 태그와 이스케이프한 텍스트만 생성합니다. 사용자가 넣은 HTML은 실행하지 않습니다.

V3 마이그레이션으로 posts와 post_publications에 rich_content를 추가했습니다. 기존 일반 텍스트는 그대로 읽고, 새 편집기로 저장할 때 서식 문서로 변환합니다. 기존 하단 이미지도 최초 편집 시 본문 끝에 삽입하여 유지합니다. 검색용 일반 텍스트를 함께 저장합니다. 페이지의 기존 sections_json에는 선택적인 bodyDoc 필드를 추가했습니다.

편집본과 발행본은 별도로 보관합니다. 자동·수동 임시저장은 기존 발행본을 바꾸지 않습니다. 저장 응답의 버전은 동일 트랜잭션에서 읽으며 오래된 창의 수정은 거부합니다. 글과 미디어의 소유권 및 기존 RBAC·CSRF 정책을 유지합니다.

## 미디어

- 파일당 5MB. JPG/PNG는 최대 1,600만 화소, 서버에서 디코딩·재인코딩합니다.
- PDF, UTF-8 TXT, DOCX, XLSX, PPTX, HWP를 다운로드 첨부로 지원합니다. 서명 또는 문서 내부 구조를 확인합니다. Office 압축 검사는 확장 크기·항목 수를 제한합니다.
- 문서 응답은 attachment Content-Disposition과 nosniff를 사용합니다. 실행 가능한 HTML/SVG 첨부는 제공하지 않습니다.
- 한 본문에 서로 다른 미디어 최대 12개. 편집본·발행본·페이지·로고가 참조하는 미디어는 삭제할 수 없습니다.
- 로고 및 이미지 섹션에는 이미지 파일만 선택할 수 있습니다.

## 관리자 동선

- 콘텐츠 아래 글·페이지·카테고리·파일을 모으고 자주 쓰는 메뉴를 펼쳐 둡니다. 사이트 꾸미기는 메뉴 설정과 통합 디자인 설정, 운영 관리는 계정과 활동 이력, 설정은 기본 정보와 외부 링크로 구성합니다.
- 연결된 카테고리·페이지의 메뉴 이름은 조회 시 원본 이름을 따릅니다. 기존 개별 메뉴 이름은 더 이상 표시하지 않으며 외부 링크만 이름을 직접 입력합니다. 200자 페이지 제목도 잘리지 않고 표시합니다.
- 글 제목은 곧바로 편집을 엽니다. 검색·카테고리·페이지 위치는 안전한 내부 목록 주소로 보존하며, 카테고리를 고른 목록에서 글쓰기를 시작하면 해당 카테고리를 선택합니다.
- 페이지는 본문 하나로 시작하고 추가 섹션은 선택합니다. 미완성 이미지·버튼 섹션의 임시저장을 허용하며 발행 검증은 유지합니다.
- 파일을 쓰는 자리에서 로고·이미지 업로드와 보관함 업로드를 제공합니다. 업로드 중 저장을 막고 완료 후 편집기 자동 저장에 연결합니다.
- 구조·설정·파일 정보 입력 오류는 입력값을 유지합니다. 카테고리·페이지·파일 삭제 제한은 같은 화면에서 사용처를 보여 줍니다.
- 글·페이지에 저장 상태, 발행본과 다른 수정, 비공개 상태를 표시하며 삭제·비공개 동작을 ‘더 보기’에 모았습니다.
- 계정 목록에서 한국어 역할명으로 변경합니다. 역할 설명은 같은 화면에서 펼칩니다.
- 순서 저장과 입력 폼의 미저장 이탈 보호를 제공합니다. 활동 이력은 임시저장 기록을 기본 필터링하고 원본 기록은 유지합니다.
- 메뉴·데이터 구조를 바꾸는 DB 마이그레이션은 필요하지 않습니다. 기존 카테고리·페이지 참조와 사용자 데이터는 유지합니다.

## 나머지 관리 기능

콘텐츠 목록의 검색·카테고리/상태 필터·페이징, 페이지 CRUD와 다섯 섹션 종류, 메뉴·카테고리 순서 관리, 공통 디자인·기본 정보·외부 링크 설정, 계정 발급·권한·활동 이력은 유지합니다. 방문 통계는 대시보드의 예시 값이며 별도 통계 화면이나 추적 기능은 없습니다.

| 역할 | 콘텐츠·미디어 | 페이지·구조·디자인·설정 | 계정·활동 이력 |
| --- | --- | --- | --- |
| SUPER_ADMIN | 전체 | 가능 | 가능 |
| ADMIN | 전체 | 가능 | 불가 |
| SUPPORTER | 본인 소유 | 불가 | 불가 |

## 검증

2026-09-25 동선 개선 후 `mvn-local.ps1 -B -ntp -Pegov43-probe verify` 결과: 28개 테스트, 실패·오류 없음. 메뉴 이름 자동 반영, 긴 페이지 제목, 입력 오류와 사용처 링크, 자동 주소 유지, 발행 상태 응답, 목록 복귀 주소 제한, 통합 설정의 원자적 저장, 임시저장 기록 필터, 미완성 페이지 임시저장을 추가 검증했다.

실제 브라우저에서는 분리된 메모리 DB로 카테고리 이름→메뉴 반영, 필터에서 글쓰기, 검색 조건 복귀, 발행 후 미반영 수정 표시, 로고·페이지 이미지 직접 업로드, 페이지 재열기, 보관함 문서 업로드, 중복 이름 입력 보존, 계정 목록 안의 역할 선택을 확인했다. 검증용 서버는 종료하고 기존 파일 DB를 사용하는 8081 서버에 최종 빌드를 적용했다.

인증·권한·CSRF·문서 형식과 미디어 참조·발행본 분리·자동저장 충돌·본문 순서와 HTML 이스케이프·DB 재시작 유지를 실제 HTTP 및 서비스 테스트로 검증합니다. 브라우저에서는 글 입력, 서식 변경, 표 편집, 사진/문서 업로드와 본문 삽입, 사진 크기/정렬/설명, 실시간 미리보기와 재열기를 확인합니다.
