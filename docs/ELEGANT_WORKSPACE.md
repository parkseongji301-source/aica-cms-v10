# AICA 공통 작업면 재정리 — 2026-09-29

티스토리의 배치를 따르는 방식에서 벗어나 AICA의 두 작업 관점과 기존 편집 화면에 맞춰 공통 디자인을 조정했다.

## 적용 범위

- 바깥 배경과 사이드바·헤더를 같은 밝은 회색으로 연결했다. 사이드바의 수직 경계선을 없애고 메뉴 간격, 작은 그룹 제목, 절제된 선택색으로 탐색 계층을 표시한다.
- 각 화면의 제목·안내·검색·목록을 하나의 흰 작업면에 담는다. 바깥 경계선과 모서리는 부드럽게 정리하고 목록·설정 내부의 중복 박스 테두리는 제거한다.
- 본문 26px 제목, 13~14px UI 글자, 여백 20~44px, 작은 버튼 모서리 등 공통 기준을 적용한다. AICA 블루는 로고·선택 표시·주요 동작에 사용하며 상태별 의미 색상은 유지한다.
- 글쓰기 본문은 흰 작업면에 이어지고 분류 속성은 옅은 보조 면으로 구분한다. 페이지 편집의 블록 목록과 운영 관리 보조 입력에도 같은 표면 기준을 적용한다.
- 모바일은 기존 접이식 메뉴와 목록 형태를 유지한다. 761~1000px에서는 콘텐츠 표만 내부 스크롤해 전체 화면이 가로로 넘치지 않게 한다.

## 기능 동결

이번 변경은 `frontend/src/calm-shell.css` 재정리와 `main.tsx`의 해당 CSS import 순서 변경뿐이다. 이전 작업의 변경 파일은 그대로 보존한다. 저장·게시·분류·버전·휴지통·권한·API·DB·migration 코드는 수정하지 않는다. 기존 로그인 스킨과 콘텐츠·공개 미리보기의 서식을 유지한다.

## 검증

- TypeScript/Vite 빌드 성공. 기존 프런트 테스트 49개 통과.
- 변경 전 `main.tsx`와 대조해 CSS import 위치 외 앱 로직이 동일함을 확인했다.
- 샘플 서버 브라우저에서 전체 콘텐츠, FAQ 빈 목록, 글쓰기·미리보기, 새 글 작성창, 기본 정보, 페이지 목록·블록 편집을 확인했다.
- 1280px·1440px 데스크톱, 1024px, 390px 모바일 화면을 시각 검토했다. 모바일 메뉴 열기·닫기와 작성창 취소를 확인했다.
- 모바일에서 문서 너비 375px / 화면 너비 375px. 820px 설정에서는 문서·화면 너비 805px이며 720px 표가 531px 내부 영역에서 스크롤됨을 확인했다. 차이는 브라우저 세로 스크롤바 너비다.
- 기존 외부 CSS 경로 및 번들 크기 빌드 경고는 유지된다.
