# 콘텐츠 작업 탐색과 공통 화면 · 6·7번

2026-09-29 `AICA_V11_IA_UX_UI_재설계안.md`와 이후 합의한 하위 사이드바 방식을 기준으로 반영했다.

## 6번: 위치에서 작성까지

- 후기 → 생활의 목록 제목을 `생활 후기`, 작성 버튼과 작성창을 `새 생활 후기 작성`으로 맞춘다. FAQ·근처 맛집도 같은 규칙을 사용한다.
- 상단에 `콘텐츠 작업 / 선배들의 SSUL / 후기 / 생활 / 글 제목`처럼 진입 경로를 표시한다. 상위 목록으로 돌아갈 수 있다. 이는 콘텐츠 분류에 따른 진입 위치이며 홈페이지에 실제 노출되는 위치를 보장하는 표시는 아니다.
- 새 글은 기존 유형·주제 기본값을 유지한다. 작성창에서 기본값의 출처와 임시보관 글 생성 시점을 설명하고, 주제 수정·복수 선택·선택 없음 기능을 유지한다. 기수나 검색 조건은 새 글에 복사하지 않는다.
- 글별로 열었던 목록의 검색·상태·페이지·분류 조건을 세션 내 React 상태로 기억한다. 다른 목록을 방문하더라도 해당 편집기의 목록 버튼은 원래 목록으로 돌아간다. 브라우저 뒤로/앞으로 이동은 기록을 덮어쓰지 않는다. 새로고침이나 직접 편집 주소 진입 시에는 주소에 포함된 분류 목록, 없으면 전체 콘텐츠로 돌아간다.
- 전체 콘텐츠의 상세 필터와 후기·FAQ·맛집의 간소화된 검색은 유지한다.

## 7번: 공통 사이드바·헤더

- 상단 헤더가 현재 작업 영역을 표시한다. 로고는 현재 영역의 첫 화면으로 이동하며, 영역 전환 버튼은 기존 전환 규칙을 유지한다.
- 공통 경로를 이름 있는 탐색 영역과 목록 구조로 제공한다. 상위 항목 이동에도 기존 미저장 이동 확인을 적용한다.
- 콘텐츠 하위 메뉴를 실제 중첩 목록으로 표시하고 부모 묶음·선택 항목을 구분한다. 연결되지 않은 분류와 로딩 상태도 문구로 구분한다.
- 사이트 관리에서는 휴지통·미디어를 `자료 관리`, 페이지·메뉴를 `페이지·메뉴`로 묶는다. 항목별 기존 권한 조건과 기능 경로는 유지한다.
- 모바일 메뉴에 닫기 버튼·바깥 영역 클릭·Escape 닫기를 제공한다. 열 때 닫기 버튼으로, 닫을 때 열기 버튼으로 키보드 초점을 옮긴다.
