# 운영 관리 UX — 10·11·12·13번

2026-09-29. `AICA_V11_IA_UX_UI_재설계안.md`의 메뉴·미디어·휴지통·버전 이력 방향을 적용했다.

## 변경 내용

- 메뉴: 연결된 페이지·분류 이름과 표시 여부를 목록에서 확인한다. 항목 저장과 순서 저장 안내를 분리하고, 순서 변경 미저장 상태를 표시한다. 기존 추가·수정·삭제·순서 저장 처리와 확인 절차는 유지한다.
- 미디어: 검색·파일 선택·정보 입력·사용 위치를 구획으로 정리한다. 등록자·크기·등록일, 대체 텍스트 도움말, 업로드 형식과 용량을 표시한다. 사용 위치의 로딩·오류·참조 없음 상태를 구분하고 같은 파일을 다시 선택해도 사용 위치 표시를 유지한다. 삭제 직전 참조 재확인과 권한 제한은 그대로다.
- 휴지통: 제목·삭제일·이전 상태·작성자/기존 카테고리·작업 순으로 정리했다. 복원 버튼을 ‘임시보관으로 복원’으로 명확히 하고 영구삭제와 구분했다. 재게시 전에는 공개되지 않는다는 안내와 기존 영구삭제 확인 체크를 유지한다.
- 버전 이력: 저장 시점·작성자·저장 이유를 우선 표시한다. 현재 작성본과 선택 버전을 비교하며 복구가 공개본에 즉시 반영되지 않는다는 안내를 정리했다. 블록 명칭은 읽기 쉬운 이름으로 표시하고 원래 전체 블록 설정은 펼침 영역에 유지한다. 복구 요청·확인·동시 수정 검사·재시도 처리는 변경하지 않았다.

## 동결 범위

프런트 배치·문구·조회 상태 표시만 변경했다. DB schema, API 계약, 권한, 게시·자동저장·버전·휴지통 업무 로직은 유지한다. 공통 메뉴 컴포넌트의 SNS/외부 링크 저장 처리는 그대로이며 별도 설정 화면 개편은 이번 범위에 포함하지 않는다.

- 예시 글의 수동 버전 저장 → 버전 비교 → 확인 → 복구, 휴지통 이동 → 영구삭제 확인 체크 미선택 시 실행 불가 → 취소 → 임시보관 복원을 확인했다.
