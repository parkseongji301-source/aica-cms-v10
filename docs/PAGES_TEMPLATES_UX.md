# 페이지·템플릿 UX — 8·9·15번

2026-09-29. `AICA_V11_IA_UX_UI_재설계안.md`를 기준으로 페이지 목록·구조 요약, 페이지 편집, 공용 템플릿 화면을 정돈했다. 공통 업무형 디자인을 유지한다.

## 변경 내용

- **8번:** 페이지 이름·상태·연결된 메뉴·최근 수정·작업 순으로 목록을 정리했다. 메뉴 미연결과 숨김 연결을 표시하고, 편집과 구조 보기를 구분했다. 구조 요약에서 블록별 편집으로 바로 이동한다.
- **9번:** 기본 편집 공간을 블록 목록과 선택한 블록 설정으로 구성했다. 미리보기는 필요할 때 열고 닫으며 작성 내용은 유지한다. 자동저장, 임시보관의 버전 저장, 기존 게시 관리의 공개 반영을 설명한다. 블록 배치·제목·서식·표시·순서·복제·삭제 기능을 유지한다.
- **15번:** 템플릿 목록의 검색·사용 상태·블록 수·수정 정보를 정리했다. 상세 설정과 버전 이력 경로를 유지한다. 불러오기에서 추가와 교체의 결과 블록 수를 미리 안내하며, 교체 재확인과 기존 30개 제한을 유지한다.

## 기능 동결

프런트 배치, 표시 문구, 미리보기 열림 상태, 기존 데이터의 목록 검색, 기존 구조 보기 경로 연결만 변경했다. DB schema, API 계약, 권한, 자동저장 요청, 게시·버전·휴지통 처리, 템플릿 준비·복사·적용 검증은 변경하지 않았다. 페이지 게시와 추가는 기존 관리 화면을 사용한다.

## 검증

- 프런트 테스트 49건, TypeScript 검사와 빌드, 공백 오류 검사 통과.
- 별도 메모리 DB의 예시 페이지로 목록 → 구조 → 특정 블록 편집을 확인했다.
- 미리보기 전환과 입력 유지, 템플릿 생성, 교체 재확인과 적용, 추가 시 2+2=4개 안내와 실제 적용, 자동저장·수동 버전 저장을 확인했다.
- 템플릿 검색 결과 없음·상세 설정을 확인하고 데스크톱 및 390px 모바일의 목록·편집 화면을 검수했다. 넓은 표는 패널 안에서 가로 스크롤한다.
- 초기 예시 블록의 등록 기록 누락으로 저장이 거부되는 것을 확인했다. 예시 화면의 기존 템플릿 적용 경로로 정상 등록된 새 블록을 만든 뒤 저장을 검증했다. 제품 코드나 검증 로직은 우회하지 않았다.
- 실제 8095에는 화면만 적용했다. 적용 전후 36개 테이블 fingerprint, schema, migration 이력과 승인 JAR·receipt·원래 실행 설정이 동일하다. 실제 운영 데이터의 편집·게시 조작 및 다른 역할 로그인 검수는 하지 않았다.
