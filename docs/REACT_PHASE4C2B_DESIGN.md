# 4C-2B block ID 탐색 설계

현재 4C-2A V8 사본을 새 사본으로 복제한다. 원본 V3, V1~V8 migration, 콘텐츠/페이지 저장 구조는 변경하지 않는다.

- 사이트 구조는 기존 메뉴의 PAGE 연결과 메뉴 밖 페이지를 그대로 사용한다. 그 아래 현재 초안 블록의 ID/제목/타입/표시 상태를 읽기 전용으로 투영한다. 별도 IA 테이블이나 페이지/블록을 생성하지 않는다.
- `GET /api/admin/next/page-structure`는 기존 PageService 페이지 조회 및 sections 파서를 사용한다. 본문을 복사하지 않고 탐색 메타데이터만 반환한다. 페이지 관리 권한을 동일하게 검사한다.
- URL은 `/admin-next/pages/{pageId}/edit?view=structure&block={blockId}`다. 사이트 관리도 같은 경로에서 view만 다르다. 두 경로는 기존 PagePanel/PageEditor 인스턴스와 저장 API를 공유한다.
- URL block이 선택의 기준이다. ID가 존재하지 않으면 첫 블록이나 유사한 제목/위치로 대체하지 않는다. 페이지는 열고 연결을 찾을 수 없음을 표시한다. ID 없는 블록은 트리에 비활성 항목으로 표시한다.
- 숨김 블록도 탐색 대상으로 표시하고 숨김 상태를 명시한다. URL 선택이 바뀌면 기존 블록 입력 영역으로 스크롤·포커스를 이동한다.
- 페이지 내 선택은 history.pushState, 페이지 기본 진입의 첫 유효 블록 표시는 replaceState로 URL을 정규화한다. 보기 전환은 현재 page/block을 유지한 채 view만 바꾼다. 뒤로/앞으로는 URL로 선택을 복원한다.
- 방문한 편집기를 유지하는 기존 캐시와 beforeunload 보호를 유지한다. 다른 화면으로 나갈 때 해당 페이지에 미저장/저장 중/업로드 중 입력이 있으면 이동 확인을 추가한다. 취소한 뒤로가기는 history 위치도 복원한다. 계속 이동해도 편집기를 버리지 않는다. 자동 저장 정책은 그대로다.
- 편집 중 블록 추가/복제/제목/숨김 변경은 같은 문서에서 파생한 탐색 표시를 갱신한다. 영구 저장소를 추가하지 않는다. 아직 저장하지 않은 새 ID 링크를 다른 창에서 열면 찾을 수 없음으로 처리한다.
- 사이트 구조 편집기, 전체 IA 등록, 공용 템플릿, 공개 홈페이지 연결은 이번 범위에서 제외한다.
