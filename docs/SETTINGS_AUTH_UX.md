## 인증 화면 적용 방식

승인 JAR·Thymeleaf 템플릿·인증 경로·폼 입력과 검증·CSRF 처리는 그대로다. `frontend/public/login-shell.css`는 로그인과 비밀번호 변경 폼에 한정된 CSS다.

UI release의 `css/flow.css`는 **승인 JAR 내부 원본 CSS 바이트 + 줄바꿈 + next-app/login-shell.css**로 만든다. `scripts/v11/serve_ui.py`는 이 결합이 정확히 일치하는지 확인한다. 그 외 정적 경로는 계속 허용하지 않는다. 전체 파일의 manifest hash 검사와 기존 런타임 검증도 유지한다. 원본 CSS 변조 거부 시험을 통과했다. 이전 next-app 전용 release도 계속 실행 가능하다.
