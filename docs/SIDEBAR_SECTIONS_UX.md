# 콘텐츠 작업 하위 메뉴와 목록 탐색 간소화

2026-09-29 사용자 요청에 따라 목록 안의 분류 탐색을 왼쪽 사이드바로 옮겼다.

- 후기 아래 생활·수업·프로젝트, FAQ 아래 준비사항·지원·선발·수업·생활·취업·지원금·프로젝트를 표시한다. 선택한 항목만 현재 위치로 강조한다.
- 후기·FAQ·근처 맛집 목록은 전체·임시보관·게시됨·비공개 상태 탭과 검색을 유지한다. 유형·기수·주제·기존 카테고리 필터와 적용 조건 영역은 표시하지 않는다.
- 전체 콘텐츠의 상세 필터는 유지한다.
- 예전 분류별 주소에 남은 기수·카테고리·임의 주제 조건은 분류별 목록 요청에 적용하지 않는다. 현재 사이드바 위치와 검색·상태·페이지로 조회하여 숨은 필터로 글이 누락되지 않게 한다. 전체 콘텐츠의 조회 조건은 기존대로 유지한다.
- 기존 분류 사전과 연결된 경로, 새 글 작성 기본값을 사용한다. 연결되지 않은 항목은 기존 보호 조건대로 비활성 표시한다.

DB·API·권한·저장·게시·버전·휴지통 로직 변경 없음. 48개 프런트엔드 테스트, TypeScript 검사와 빌드 통과. 분류별 조회의 숨은 조건 제거와 전체 콘텐츠 조건 유지를 기존 테스트에서 검증했다.

별도 메모리 예시 환경에서 사이드바 계층, FAQ 검색·상태 선택, 후기 필터 제거, 전체 콘텐츠 상세 필터 유지 및 화면 배치를 확인했다. 이 예시 환경에는 주제 사전이 없으므로 하위 항목은 비활성 상태로 확인했다. 실제 운영 DB의 기존 사본을 읽기 전용으로 조회하여 후기 3개·FAQ 7개 주제 코드가 활성 상태로 올바른 유형에 연결되어 있음을 확인했다. 하위 경로와 작성 기본값은 기존 단위 테스트로 검증했다. 운영 계정 로그인 및 운영 데이터 작성은 수행하지 않았다.
